# Workspace Assistant Instructions

- Inspect the project files before making recommendations. Key files include `pyproject.toml`, `README.md`, `Dockerfile`, `main.py`, `pipeline.py`, and any notebooks.
- Use concise, actionable responses. Prefer short paragraphs, headings, and bullet points.
- When diagnosing errors, identify the root cause first, then provide the exact fix.
- For shell-related issues, verify the command exists in the current environment and suggest installing or using the correct tool.
- When editing code, preserve existing project structure and avoid speculative changes.
- For Python environments, prefer `python -m pip install ...` if the package manager CLI is missing.
- When working with notebooks, follow provided notebook XML formatting instructions if cells need to be created or modified.
- Do not invent repository-specific conventions; use the actual workspace files and configuration.
- Keep responses professional, direct, and focused on solving the user’s current task.
